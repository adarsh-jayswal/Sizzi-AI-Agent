    Quick tips for using SIZZI effectively.

    New chat: Start a fresh conversation from the sidebar.
    Send a message: Type in the composer and press Enter or click the send button.
    Stop generation: Use the stop button while the agent is responding.
    Switch conversations: Select a different thread from the sidebar.
    Change appearance: Use the theme toggle in the account menu.
    Access Profile: Open the account menu and select Profile.
